# ✦ STAR:FALL

**Status:** Em desenvolvimento  
**Plataforma:** Mobile (Android)  
**Tecnologia principal:** Flutter / Dart

## 📖 Sobre o projeto

O **STAR:FALL** é um projeto pessoal desenvolvido com o objetivo principal de **estudar e adquirir experiência prática com Flutter e a linguagem Dart**, explorando os conceitos, ferramentas e possibilidades do desenvolvimento de aplicativos mobile.

Como forma de aplicar esses conhecimentos, foi idealizado um aplicativo de desenvolvimento pessoal inspirado em sistemas de progressão de RPG, especialmente nas mecânicas de missões, níveis e atributos presentes em *Solo Leveling*.

A proposta consiste em transformar atividades cotidianas em um sistema de treinamento e evolução, no qual os usuários poderão criar e concluir missões (*Quests*), acumular experiência e participar de desafios (*Challenges*) destinados a avaliar conhecimentos e habilidades desenvolvidas.

O projeto também servirá como ambiente de experimentação para conceitos de arquitetura de software, gerenciamento de estado, persistência de dados e integração com inteligência artificial.

## 🎯 Objetivos

- Aprender Flutter e Dart por meio do desenvolvimento de uma aplicação prática.
- Explorar a construção de interfaces e componentes reutilizáveis.
- Compreender navegação, gerenciamento de estado e persistência de dados em aplicativos mobile.
- Implementar um sistema de missões personalizáveis.
- Criar mecânicas de experiência (XP), níveis e progressão.
- Desenvolver desafios para avaliar conhecimentos e habilidades.
- Explorar diferentes áreas do desenvolvimento pessoal.
- Investigar a integração e execução local de modelos de inteligência artificial.

## ⚙️ Funcionalidades planejadas

| Módulo | Descrição |
|---|---|
| Home | Painel principal do usuário |
| Login / Register | Autenticação e gerenciamento de acesso |
| Profile | Informações da conta e configurações |
| Quests | Criação, gerenciamento e conclusão de missões |
| Challenges | Desafios para avaliar habilidades desenvolvidas |
| Status | Acompanhamento de níveis, experiência e atributos |
| STAR AI | Assistente de IA para sugestão e personalização de missões |

### Sistema de progressão

O sistema será dividido em duas mecânicas principais:

**Quests — Treinamento**

Atividades realizadas pelo usuário que concedem experiência e contribuem para desbloquear novos desafios.

**Challenges — Avaliação**

Desafios destinados a verificar o progresso do usuário por meio de questionários, atividades práticas ou outros critérios de avaliação.

A conclusão bem-sucedida de Challenges poderá conceder pontos de atributos e registrar conquistas específicas dentro do aplicativo.

## 🧠 Inteligência Artificial

Uma das propostas do STAR:FALL é investigar a utilização de modelos de linguagem para gerar missões personalizadas a partir dos objetivos, interesses e progresso do usuário.

O projeto pretende explorar especialmente a possibilidade de executar modelos de IA diretamente no dispositivo (*On-device AI*), reduzindo a dependência de serviços externos e APIs pagas.

A integração será desenvolvida e avaliada em etapas posteriores.

## 🚧 Desenvolvimento

O STAR:FALL encontra-se em fase inicial de desenvolvimento.

As funcionalidades descritas representam o escopo planejado e poderão ser modificadas conforme os estudos, testes e necessidades identificadas durante a implementação.

## 📌 Propósito

O STAR:FALL é, principalmente, um **projeto de aprendizado e experimentação prática com Flutter e Dart**.

Seu desenvolvimento busca consolidar conhecimentos em programação mobile por meio da construção gradual de uma aplicação funcional, documentando a evolução técnica, os desafios encontrados e as soluções implementadas.

O projeto também integra o portfólio pessoal de desenvolvimento de software.
